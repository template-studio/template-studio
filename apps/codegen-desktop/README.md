# Template Studio - 桌面应用

## 🎯 项目概述

基于 Tauri + Vue 3 + Naive UI 的模板生成桌面应用，提供现代化的图形界面体验。

### 核心特性

✅ **桌面应用优势**
- 🚀 原生性能：使用 Rust 后端，毫秒级渲染
- 📱 固定布局：三栏设计，充分利用屏幕空间
- ⌨️ 快捷键支持：键盘操作更高效
- 🎨 精美界面：Naive UI 组件库
- 🌙 暗色模式：保护开发者眼睛

✅ **功能完整性**
- 📦 模板库管理：浏览、搜索、选择模板
- ⚙️ 变量配置：实时预览、智能验证
- 👁️ 实时预览：即时查看渲染结果
- 🎯 一键生成：点击按钮生成项目
- 📊 状态栏：实时显示操作状态

## 📦 安装与运行

### 开发模式

```bash
# 安装依赖
cd apps/scaffold-desktop
npm install

# 启动开发服务器
npm run tauri dev
```

### 生产构建

```bash
# 构建 Web 前端
npm run build

# 构建 Tauri 应用
npm run tauri build
```

## 🏗️ 架构设计

```
scaffold-desktop/
├── src/                      # Vue 源码
│   ├── components/           # 组件目录
│   │   ├── DesktopLayout.vue   # 主布局组件
│   │   ├── TemplateConfig.vue  # 模板配置
│   │   ├── PreviewPane.vue     # 预览面板
│   │   └── StatusBar.vue       # 状态栏
│   ├── App.vue               # 根组件
│   └── main.js               # 入口文件
├── src-tauri/                # Rust 后端
│   ├── src/
│   │   └── lib.rs            # Tauri 命令
│   ├── Cargo.toml             # Rust 依赖
│   └── tauri.conf.json       # Tauri 配置
└── package.json              # Node 依赖
```

### 数据流

```
用户操作 → Vue 组件 → Tauri IPC → Rust 后端
                ↓
         template_core (本地渲染)
                ↓
         文件系统写入
```

## 🔧 桌面端特性

### 1. 模板选择

- 📂 分类导航：Web、CLI、桌面应用
- 🔍 实时搜索：按名称、描述过滤
- ⭐ 精选标记：突出优质模板
- 📋 列表展示：清晰的信息层级

### 2. 变量配置

- 📝 多种输入类型：
  - 字符串输入
  - 多行文本
  - 数字输入
  - 布尔开关
  - 下拉选择
- ✅ 智能验证：必填项、格式校验
- 🎨 实时反馈：输入时即时更新预览

### 3. 实时预览

- 📁 文件树：展示项目结构
- 💻 代码预览：语法高亮显示
- 🔄 热更新：变量改变自动刷新
- 📊 文件统计：显示生成文件数量

### 4. 桌面应用优势

#### 对比 Web 应用

| 特性 | Web 应用 | 桌面应用 |
|------|---------|---------|
| 窗口控制 | 浏览器标签页 | 原生窗口，完全控制 |
| 性能 | 受限沙箱 | 原生性能，无限制 |
| 文件系统 | 受限 API | 完整文件系统访问 |
| 快捷键 | 浏览器快捷键 | 自定义快捷键系统 |
| 系统集成 | 受限 | 深度系统集成 |
| 离线使用 | 需要服务器 | 完全离线可用 |

#### 对比 TUI 应用

| 特性 | TUI | GUI 桌面 |
|------|-----|---------|
| 视觉效果 | 文本界面 | 图形界面，更直观 |
| 交互方式 | 键盘操作 | 鼠标 + 键盘，更灵活 |
| 学习曲线 | 需要记忆快捷键 | 直观，易于上手 |
| 信息密度 | 高密度文本 | 适度，易于理解 |
| 预览能力 | 文本预览 | 图形化预览 |

## 🚀 快速开始

### 1. 启动应用

```bash
npm run tauri dev
```

### 2. 选择模板

- 在左侧选择模板分类
- 在列表中选择具体模板
- 查看模板描述和标签

### 3. 配置变量

- 填写项目名称等必填项
- 配置可选变量
- 实时查看右侧预览

### 4. 生成项目

- 点击"生成项目"按钮
- 选择输出目录
- 等待生成完成
