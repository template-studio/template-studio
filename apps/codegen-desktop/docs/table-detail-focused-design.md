# 表详情页面设计方案（代码生成核心版）

## 🎯 核心目标

**聚焦代码生成**，为 AI 和模板引擎提供充足的上下文信息，支持：
1. **字段级别配置**：映射关系、验证规则、显示标签
2. **AI 上下文注入**：给 AI 提供项目的生成规范
3. **代码预览**：实时预览生成的代码
