### Phase 1: AI 服务配置

#### 1.1 打开设置页面

#### 1.2 配置 AI 提供商

**DeepSeek 配置：**
- [ ] 点击 **DeepSeek** 提供商
- [ ] 启用开关：打开
- [ ] 输入 API 密钥（从 DeepSeek 平台获取）
- [ ] 点击保存按钮（💾 图标）
- [ ] 确认显示"保存成功"

**GLM 配置（可选）：**
- [ ] 点击 **智谱 GLM** 提供商
- [ ] 启用开关：打开
- [ ] 输入 API 密钥
- [ ] 点击保存

**LongCat 配置（可选）：**
- [ ] 点击 **LongCat** 提供商
- [ ] 启用开关：打开
- [ ] 输入 API 密钥
- [ ] 点击保存

#### 1.3 设置默认服务

- [ ] 点击 **默认服务**（AI 服务二级菜单顶部）

- [ ] 选择 **默认模型**（如：deepseek-chat）
- [ ] 点击 **保存设置**
- [ ] 确认显示"默认服务已保存"

### Phase 3: 测试 AI 建表功能

#### 3.1 打开表管理页面

- [ ] 点击刚创建的项目卡片
- [ ] 进入表管理页面
- [ ] 确认显示 **AI 建表** 按钮

#### 3.2 测试简单表创建

**步骤 1：输入描述**
- [ ] 点击 **AI 建表** 按钮
- [ ] 确认对话框打开
- [ ] SQL 类型选择：`MySQL`
- [ ] 表描述输入：
  ```
  用户表：
  - id：主键，自增
  - username：用户名，唯一，不为空，最大长度 50
  - email：邮箱，唯一，不为空
  - created_at：创建时间，默认当前时间
  ```
- [ ] 点击 **生成 SQL**

**步骤 2：预览 SQL**
- [ ] 确认步骤指示器显示到第 2 步
- [ ] 确认 SQL 文本框中显示类似内容：
  ```sql
  CREATE TABLE users (
      id INT AUTO_INCREMENT PRIMARY KEY,
      username VARCHAR(50) NOT NULL UNIQUE,
      email VARCHAR(255) NOT NULL UNIQUE,
      created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
  );
  ```
- [ ] 确认 SQL 格式正确
- [ ] 点击 **下一步**

**步骤 3：预览字段**
- [ ] 确认步骤指示器显示到第 3 步
- [ ] 确认显示字段表格，包含以下列：
  - [ ] 表名：users
  - [ ] 字段：id, username, email, created_at
  - [ ] 每个字段显示：类型、是否可空、是否主键
- [ ] 确认字段解析正确：
  - [ ] id：INT，主键
  - [ ] username：VARCHAR(50)，不可空，唯一
  - [ ] email：VARCHAR(255)，不可空，唯一
  - [ ] created_at：TIMESTAMP，默认值
- [ ] 点击 **完成**

**步骤 4：执行结果**
- [ ] 确认步骤指示器显示到第 4 步
- [ ] 确认显示绿色 **成功** 提示
- [ ] 点击 **关闭**
- [ ] 确认表管理列表中显示 `users` 表
- [ ] 点击 `users` 表的 **查看字段** 按钮
- [ ] 确认显示所有字段信息

#### 3.3 测试多表创建

**重新打开 AI 建表**
- [ ] 点击 **AI 建表** 按钮

**输入多表描述**
- [ ] SQL 类型选择：`MySQL`
- [ ] 表描述输入：
  ```
  分类表：
  - id：主键，自增
  - name：分类名称，不为空
  - parent_id：父级ID，默认 0

  商品表：
  - id：主键，自增
  - name：商品名称，不为空
  - price：价格，DECIMAL(10,2)，不为空
  - category_id：分类ID，外键关联 categories
  - stock：库存，INT，默认 0
  ```
- [ ] 点击 **生成 SQL**

**验证多表解析**
- [ ] 确认生成了多个 CREATE TABLE 语句
- [ ] 点击 **下一步**
- [ ] 确认字段预览显示多个表（categories 和 products）
- [ ] 点击 **完成**
- [ ] 确认两个表都创建成功

#### 3.4 测试 AI 修复功能

**创建有错误的表**
- [ ] 点击 **AI 建表**
- [ ] 手动输入有错误的 SQL：
  ```sql
  CREATE TABLE test_table (
      id INT AUTO_INCREMENT PRIMARY KEY,
      name VARCHAR(100) NOT NULL
      email VARCHAR(255) UNIQUE
  );
  ```
  （注意：name 和 email 之间缺少逗号）

**步骤 2：手动编辑 SQL**
- [ ] 在步骤 2 的 SQL 文本框中粘贴错误的 SQL
- [ ] 点击 **下一步**
- [ ] 确认显示 **解析错误** 提示
- [ ] 点击 **上一步** 回到步骤 2
- [ ] 点击 **重新生成**（如果有重新生成按钮）
- [ ] 或者手动修复 SQL（添加逗号）
- [ ] 点击 **下一步**

**测试 AI 修复**
- [ ] 如果步骤 4 显示错误
- [ ] 点击 **AI 修复** 按钮
- [ ] 确认显示"正在修复..."
- [ ] 等待修复完成
- [ ] 确认 SQL 已被修复
- [ ] 确认自动跳转到步骤 3
- [ ] 点击 **完成**
- [ ] 确认表创建成功
