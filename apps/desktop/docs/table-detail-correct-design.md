# 表详情页面设计方案（符合现有项目风格）

## 📋 页面定位

**表详情页面** = 表的代码生成配置页面

**导航路径**：
```
项目列表 → 点击项目 → 表管理（TablesView）
→ 点击表名 → 表详情页面（TableDetail）
         ↑
      返回按钮
```

**与现有菜单的关系**：
- **表管理菜单** → 表列表（TablesView） → 表详情（TableDetail）← 新增
- **规范管理菜单** → 项目规范（PreferencesView）← 已存在

## 📋 配置项详解

### 1. 字段基本信息

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 字段名 | 数据库字段名（只读） | - |
| 数据库类型 | VARCHAR(255)（只读） | - |
| 允许空值 | 是否可为 NULL | 从数据库读取 |
| 字段说明 | 字段注释/说明 | 从数据库读取 |
| 参与代码生成 | 是否生成代码 | ☑ |

### 2. 类型映射

**为每种语言配置代码类型**：

| 数据库类型 | Java | Go | Python | TypeScript |
|-----------|------|-------|--------|------------|
| VARCHAR(255) | String | string | str | string |
| BIGINT | Long | int64 | int | number |
| TINYINT | Integer | int8 | int | number |
| TIMESTAMP | LocalDateTime | time.Time | datetime | Date |

**功能**：
- ✅ 自动推荐类型（基于数据库类型）
- ✅ 保存为默认映射（新建字段时自动应用）
- ✅ 支持自定义类型

### 3. 验证规则

**基础验证**：
- ☑ 必填 (required) → `@NotNull`
- ☑ 唯一 (unique) → `@Column(unique = true)`
- ☐ 邮箱 (email) → `@Email`
- ☐ 手机号 (phone)
- ☐ URL (url)

**范围验证**：
- ☐ 长度范围：最小 [__] 最大 [255]
  → `@Size(min=2, max=255)`
- ☐ 数字范围：最小 [____] 最大 [____]
  → `@Min(0) @Max(100)`

**自定义验证**：
- ☐ 正则表达式：`[^[a-z0-9._%+-]+@[a-z0-9.-]+\\.[a-z]{2,}$]`
  → `@Pattern(regexp = "...")`
- 自定义验证器：`[EmailValidator________]`

**保存模板**：
- 保存为"邮箱验证模板"
- 下次直接选择模板应用

### 4. 前端展示配置

| 配置项 | 说明 | 用途 |
|--------|------|------|
| 显示标签 | "邮箱" | 列表、表单、详情显示 |
| 占位符 | "请输入邮箱地址" | 表单输入提示 |
| 帮助提示 | "用于登录和找回密码" | 表单下方提示文本 |
| 表单组件 | Input/Textarea/Select... | 自动选择组件类型 |
| 显示位置 | ☑列表 ☑详情 ☑表单 ☑搜索 ☐导出 | 控制显示位置 |
| 列表配置 | 列宽、对齐、排序、筛选 | 列表显示配置 |

### 5. API 文档配置

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 示例值 | API 文档中的示例 | `user@example.com` |
| 字段描述 | API 文档描述 | "用户登录邮箱" |
| 是否敏感 | 是否脱敏显示 | ☐（密码、手机号） |
| 脱敏规则 | 脱敏显示规则 | `****@***.***` |

### 6. AI 提示

**给 AI 的额外提示**（文本域）：
```
用户邮箱字段：
- 必须唯一
- 用于登录认证
- 需要邮箱格式验证
- 生成代码时添加 @Email 注解
```

**提示词模板**（高级）：
```
为 {language} 生成 {entity} 的 {fieldName} 字段代码：
- 数据库类型: {dbType}
- 代码类型: {codeType}
- 验证规则: {validations}
- 字段描述: {comment}
- 前端组件: {frontendComponent}
```

## 📊 数据存储

### 新增表：field_config

```sql
CREATE TABLE field_config (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    table_id INTEGER NOT NULL,
    field_name VARCHAR(255) NOT NULL,

    -- 基本信息
    comment TEXT,
    is_enabled INTEGER DEFAULT 1,  -- 是否参与代码生成

    -- 类型映射（JSON）
    -- {"java": "String", "go": "string", "python": "str"}
    type_mapping TEXT,

    -- 验证规则（JSON）
    -- {"required": true, "email": true, "min": 2, "max": 255}
    validations TEXT,

    -- 前端配置（JSON）
    -- {"label": "邮箱", "component": "Input", "show_in_list": true}
    frontend_config TEXT,

    -- API 文档（JSON）
    -- {"example": "user@example.com", "description": "..."}
    api_doc TEXT,

    -- AI 提示（TEXT）
    ai_hints TEXT,

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (table_id) REFERENCES project_tables(id),
    UNIQUE(table_id, field_name)
);
```

### Tauri 命令
```rust

```

## 🎯 总结

**核心特点**：
1. ✅ **无Tab设计**：使用折叠面板或左右分栏
2. ✅ **符合现有风格**：与 TablesView、PreferencesView 风格一致
3. ✅ **聚焦代码生成**：所有配置都服务于代码生成
4. ✅ **字段级配置**：每个字段独立配置类型映射、验证规则
5. ✅ **应用项目规范**：可以一键应用 PreferencesView 的配置

**页面关系**：
```
项目列表
  ↓ 点击项目
项目工作区
  ├─ 表管理 (TablesView)
  │    └─ 点击表名 → 表详情 (TableDetailView) ← 新增
  │
  └─ 规范管理 (PreferencesView)
       └─ 项目级规范配置
```
