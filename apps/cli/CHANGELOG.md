# CLI 应用更新日志

## [0.1.0] - 2025-02-04

### ✅ 新增功能

#### CLI 模式
- ✅ 完整的命令行参数解析(clap 4.4)
- ✅ 项目创建命令 (`create`)
  - 支持项目名称、模板选择、输出目录配置
  - 支持 TUI 模式自动切换
  - 支持 Git 自动初始化
  - 支持强制覆盖
- ✅ 模板管理命令 (`template`)
  - `list` - 列出所有可用模板
  - `info` - 显示模板详细信息
  - `search` - 搜索模板
- ✅ 配置管理命令 (`config`)
  - `show` - 显示当前配置
  - `set` - 设置配置项

#### TUI 模式
- ✅ 基于 ratatui 0.23 的现代化终端界面
- ✅ 7步向导式流程:
  1. 欢迎页面
  2. 项目名称输入
  3. 输出目录设置
  4. 模板搜索
  5. 模板选择
  6. 变量配置(框架就绪)
  7. 完成确认
- ✅ 键盘快捷键支持:
  - `Enter/Space` - 确认/继续
  - `Esc` - 返回/退出
  - `↑/↓` 或 `j/k` - 上下导航
  - `/` - 搜索
  - `q` - 退出
- ✅ 实时状态显示和进度指示
- ✅ 错误提示和处理

#### 核心功能
- ✅ HTTP API 客户端
  - 支持远程模板列表获取
  - 支持模板搜索和过滤
  - 支持模板渲染
  - API 密钥认证
- ✅ 配置管理
  - TOML 格式配置文件
  - 自动创建默认配置
  - 命令行参数覆盖配置文件
- ✅ 项目生成器
  - 文件和目录生成
  - 递归创建目录结构
  - 支持强制覆盖已存在的目录
  - Git 仓库自动初始化

### 🔧 技术栈

- **CLI 框架**: clap 4.4
- **TUI 框架**: ratatui 0.23
- **终端操作**: crossterm 0.27
- **HTTP 客户端**: reqwest 0.11
- **异步运行时**: tokio (workspace)
- **配置管理**: config 0.14 + toml 0.8
- **序列化**: serde + serde_json (workspace)
- **错误处理**: anyhow 1.0
- **日志**: tracing (workspace)

### ⚠️ 已知限制

1. **后端依赖**
   - 需要后端 API 服务运行
   - API 端点需要与后端匹配

2. **TUI 终端兼容性**
   - 某些终端可能显示异常
   - 推荐使用 Windows Terminal / 现代 Terminal

3. **待实现功能**
   - 变量配置界面(仅有框架)
   - 从配置文件加载变量
   - 模板预览功能
   - 进度条显示
   - 离线模式
