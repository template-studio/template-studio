## 2. 复杂组件操作

### 2.1 对象类型 (object)

| 编号 | 测试项 | 操作步骤 | 预期结果 |
|------|--------|----------|----------|
| 2.1.1 | 添加对象 | 点击组件库"对象" | 添加成功，字段名为 `config1`，显示展开箭头 |
| 2.1.2 | 展开对象 | 点击展开箭头 | 显示子字段区域（初始为空） |
| 2.1.3 | 右键进入内部 | 右键对象 → 选择"进入内部编辑" | 进入对象内部，面包屑显示导航路径 |
| 2.1.4 | 对象内添加组件 | 进入内部 → 添加文本框 | 添加成功，返回后展开面板显示子字段 |

### 2.2 对象数组类型 (object_arr)

| 编号 | 测试项 | 操作步骤 | 预期结果 |
|------|--------|----------|----------|
| 2.2.1 | 添加对象数组 | 点击组件库"对象数组" | 添加成功，字段名为 `items1`，显示展开箭头 |
| 2.2.2 | 展开对象数组 | 点击展开箭头 | 显示子字段区域（初始为空） |
| 2.2.3 | 右键进入内部 | 右键对象数组 → 选择"进入内部编辑" | 进入内部，面包屑显示导航路径 |
| 2.2.4 | 内部添加组件 | 进入内部 → 添加多个组件 | 添加成功，返回后展开面板显示所有子字段 |
| 2.2.5 | 展开面板显示子字段 | 添加子字段后 → 展开对象数组 | 子字段列表正确显示所有添加的字段 |

### 2.3 数组类型 (array)

> **注意**：数组（array）是简单数组，只支持单一元素类型（字符串/整数/数字/布尔），不支持子字段。如需存储复杂对象，请使用"对象数组"（object_arr）。

| 编号 | 测试项 | 操作步骤 | 预期结果 |
|------|--------|----------|----------|
| 2.3.1 | 添加数组 | 点击组件库"数组" | 添加成功，字段名为 `list1`，无展开箭头 |
| 2.3.2 | 右键菜单 | 右键数组 | 只显示"删除"选项，无"进入内部编辑" |
| 2.3.3 | 属性面板编辑元素类型 | 选中数组 → 属性面板选择元素类型 | 元素类型更新成功（字符串/整数/数字/布尔） |
| 2.3.4 | 数组与对象数组的区别 | 对比数组和对象数组 | 数组：无子字段，只能选元素类型；对象数组：有子字段，可进入内部编辑 |

## 10. 快速回归测试清单

每次修改后执行以下核心测试：

- [ ] 添加基础组件（文本框、数字框）
- [ ] 添加对象，进入内部，添加子字段
- [ ] 添加对象数组，进入内部，添加子字段
- [ ] 添加数组，在属性面板编辑元素类型（不进入内部）
- [ ] 进入嵌套层级，选中子字段，查看属性面板
- [ ] 在嵌套内删除组件，再添加新组件
- [ ] 展开对象数组，查看子字段列表
- [ ] 连续添加多个相同类型组件，验证字段名不重复
- [ ] 修改组件类型，验证属性面板更新
- [ ] 保存后关闭，重新打开验证数据恢复
